# 慧选助手 (Huixuan Assistant)

面向消费者的**商品选购辅助工具** —— 以 DeepSeek Harness (DSH) 插件形态提供。

## 这是什么

用户在浏览商品时，可以把商品链接提交给工具，工具通过**拼多多开放平台官方接口**获取该商品的公开信息，并以结构化视图整理展示，帮助用户更清晰地了解商品、做出选购决策。

核心能力：

- **商品信息整理** —— 提交商品链接，获取公开信息（标题、价格、规格参数、销量、评价概览）
- **多商品对照** —— 多件商品的参数与价格并列展示，方便比较
- **选购参考** —— 基于公开信息给出结构化的对比与选购建议
- **导流购买** —— 生成推广链接，跳转至商品页面完成购买

## 数据来源与合规声明

本工具**仅使用拼多多开放平台官方接口**获取公开商品数据。

- 不抓取网页数据
- 不存储原始商品数据
- 不涉及用户隐私信息
- 不涉及交易订单数据
- 所有商品信息展示后均跳转至原平台完成购买
